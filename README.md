VoiceFlow - Free, open-source, system-wide voice dictation app.
A privacy-first alternative to Wispr Flow. Cross-platform. Zero cost.

## Features
- Push-to-talk or toggle dictation via global hotkey
- Local Whisper GPU-accelerated transcription
- Optional cloud LLM post-processing (BYOK)
- System-wide text injection (any app)
- Per-app profiles (no screenshots)
- Open source, free forever
